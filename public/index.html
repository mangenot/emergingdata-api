EmergingData API

Read access to the EmergingData observation table. All routes return JSON, or CSV with format=csv. Add your key as the x-api-key header or the api_key parameter.

RouteParametersReturns
/api/seriescountry, indicator (comma lists allowed), from, to (YYYY-MM)the latest vintage of each observation, with unit and note
/api/statuscountry (optional)one line per series: first and last observation, rows, frequency, stale flag
/api/catalogtype = indicators, countries or events; country for eventsthe registry as held in the database

Example: /api/series?country=BGD&indicator=INF_CPI,FX_USD&from=2024-01&format=csv
